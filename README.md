# Karate coaching: paper notebook

## Run
1. `cp .env.example .env` and set GROQ_API_KEY (add DATA_DIR if data is elsewhere).
2. Put the data in `data/` (see data/README.md).
3. Copy the three backend files listed below into `backend/app/rag/`.
4. `docker compose up --build`
5. Open http://localhost:8888 (token = JUPYTER_TOKEN) and run
   `backend/app/notebooks/02_Master_Pipeline_fixed_v4.ipynb`.

## Copy from the old project (not generated here)
- backend/app/rag/feature_extractor.py
- backend/app/rag/data/coaching_chunks.json   (the 34 coaching chunks)
- (optional) backend/app/rag/retriever.py     (only if USE_APP_CHROMA=True, needs torch: not installed here)

`backend/app/rag/data/master_reference_sequences.json` is generated by notebook section 3.
Outputs go to `backend/app/notebooks/Results/`.
